- 気づき・疑問：
  - Gemini API は会話を覚えないので、続けて質問するには過去の質問と回答を毎回すべて送り直す必要がある
  - そのため、会話が長くなるほど入力トークンが増える。長い会話では、古い履歴を削るか要約する必要がありそう
  - 失敗したやり取りは SDK が履歴に残さないので、同じ質問を入力し直せばやり直せる
